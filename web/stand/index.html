Прошивка стенда UlpanIR

ESP32-C6 Super Mini становится стендом: шьёт CH592F на плате пульта через гребёнку J1 и проверяет плату. Прошивка стенда заливается в Super Mini один раз, из браузера.

Прошить из браузера

  1. Chrome или Edge на компьютере (нужен Web Serial; Safari и Firefox его не умеют).
  2. Зажать BOOT на Super Mini, вставить USB, отпустить BOOT.
    Для новой платы можно без BOOT. Если на плате уже прошивка стенда — только так: стенд отключает сброс по USB, чтобы открытие порта его не перезапускало.
  3. Нажать «Прошить», выбрать порт платы (USB JTAG/serial debug unit) → Install.
    Браузер не умеет Web Serial — нужен Chrome или Edge на компьютере. Web Serial работает только по https или с localhost.

    Образа рядом со страницей нет. Собрать и положить: make -C stand web, страница локально — make -C stand serve.

  4. Вынуть и вставить USB — появится порт стенда. Проверка: 
    uv run stand/host/stand.py monitor '#info'
    Ответ — # ulpanir_stand <версия> uptime=….

Или из консоли

Собрать PlatformIO и прошить (порт найдётся сам):

make -C stand flash

Готовым образом — один файл с адреса 0x0:

esptool --chip esp32c6 write-flash 0x0 ulpanir_stand-esp32c6.bin
