# Сохранённые варианты разводки PCB1

| Версия | Дата | Копия в EasyEDA | Выгрузка | Что это |
|---|---|---|---|---|
| v1 | 26.11.2026 | `PCB1_trace_v1_2026-11-26` (проект UlpanIR, без привязки к Board1) | `v1_2026-11-26.json`, `v1_2026-11-26.png` | первая полная разводка: 0 неразведённых связей, DRC чист (кроме намеренного касания GND–ANT_F у PIFA), позиционные обозначения 1,14 мм |

Выгрузка — все примитивы платы из API EasyEDA Pro (единицы — mil, 1 mil = 0,0254 мм): компоненты
(`comps`: позиция, поворот, слой, габарит), выводы (`pins`), свободные площадки (`pads`), дорожки (`lines`,
`polys`), переходы (`vias`), заливки (`pours`), запретные зоны (`regions`), заливки-фигуры (`fills`).
