# История решений и изменений планов

Что меняли в планах, когда и почему. Подробности — в коммитах (`git log`) и в документах, на которые
ссылается запись. Новое — в конец.

## 25.11.2026

- **Задача разбита на четыре** OpenSpec-изменения: ИК (`add-ir-nec-transmit`), настройка по BLE
  (`add-remote-config`), питание (`add-power-latch`), плата (`add-board-hardware`).
- **МК: nRF52810 → WCH CH592F** (решение владельца). В 4–8 раз дешевле, есть на складе JLCPCB.
  Исходный пакет под nRF перенесён в `docs/source_package_v5_nrf/` как исторический.
- **Индикатор** — один красный светодиод на ШИМ для всех сигналов, ≤ 2 мА.
- **Защёлка питания** утверждена с номиналами (`openspec/changes/add-board-hardware/design.md`).
  Cm: 33 → **47 нФ** — базовой детали 33 нФ на JLCPCB нет.
- **DC-DC CH592 выключен** — дроссель стал бы «расширенной» деталью, выигрыш в токе мал
  (`hardware/README.md` §3).
- **Габариты платы 37 × 24 мм** — оценка по фото донора принята владельцем как точная.
- **ИК-светодиод:** основной VSMY14940; замена Amicc A-SP158IR1C-A02-2D паяется вручную на те же
  площадки Vishay (`hardware/README.md` §2.1).
- **Накопитель:** сначала C4 + C10 = 2 × 100 мкФ, затем **C4 = 22 мкФ** (паяет JLCPCB), **C10 = 100 мкФ —
  только площадка**, паять вручную при нехватке (`hardware/README.md` §2.2).
- **Антенна: TI AN043 → PIFA WCH под FR4 1,2 мм**, π-цепь как на CH592EVT (C11, C12 не ставятся,
  R9 = 0 Ом). Причина — рекомендации производителя чипа (`hardware/README.md` §4).
- **Кварц: TAITIEN C124330 → SOSET C7420782** (±10 ppm по документу WCH). **Плата — 1,2 мм** (под шаблон
  антенны).
- **USB не выводится**; BOOT (PB22) не выведен. Прошивка — WCH-LinkE по 2-проводной отладке.
- **Индикатор: PA12 → PB4** (PWM7) — короче дорожка к R5.
- **Площадки прошивки TP1–TP10 → ряд из 6 отверстий J1** с шагом 2,54 мм.

## 26.11.2026

- **Разводка v1** сохранена (`hardware/pcb_versions/`), затем переделана.
- **Разводка v2:** детали у кнопок сгруппированы зеркально, обвязка питания собрана у контакта BAT+,
  накопители — у ИК-каскада; **порядок гребёнки J1 перевёрнут** (RX, TX, TCK, TIO, 3V3, GND слева
  направо), чтобы линии от МК не пересекались; питание светодиодов — 0,5 мм.
- **Разводка v3** (текущая):
  - магистраль VBAT_SW — **по нижнему слою**, по 3 перехода на каждой смене слоя;
  - **кнопка B: PA5 → PB7** (решение владельца: PA5 можно менять, PB10 — нет; IR_PWM остаётся на PA10);
  - **гребёнка J1 — деталь в схеме** (PZ254V-11-06P), **в BOM не входит**;
  - **TP_VBAT убрана** (решение владельца) — батарейку до ключа мерить на BAT+;
  - переходы не ближе 0,2 мм к площадкам.
- **Держатель CR2032 (C7498148) исключён из BOM** — на плате пазы BAT+/BAT− под контакты донора.
- **Прошивка своей платы — WCH-LinkE через J1**; встроенный загрузчик по USB остаётся только для отладочной
  платы (`add-ir-nec-transmit`). Требование в `add-board-hardware` переписано с «площадок для
  загрузчика» на «гребёнку прошивки».
- **Выгрузка в репозиторий:** проект EasyEDA `hardware/easyeda/UlpanIR.epro2`, схема
  `hardware/schematic/UlpanIR_schematic_easyeda.pdf`, Gerber `hardware/fab/`. Черновые рисунки схемы
  25.11.2026 перенесены в `hardware/schematic/history_2026-11-25/`.
- **Схема приведена к реализации:** подпись антенны — PIFA WCH, у C11/C12 значение «NC» вместо 100 нФ.

- **Прошивка начата** (`add-ir-nec-transmit`): компилятор — xPack riscv-none-elf-gcc 15 вместо компилятора WCH,
  поэтому прерывания объявлены стандартным атрибутом (`-DINT_SOFT`); нужная часть SDK `openwch/ch592` лежит в
  `firmware/vendor/`. На отладочной плате WeAct ИК-выход — PB10 (переназначенный TMR1), а не PA10: на PA10/PA11
  у WeAct кварц 32 кГц. Железа пока нет — проверено unit-тестами и сборкой, не на плате.
- **Разводка v3a:** пазы контактов батарейки BAT+/BAT− были повёрнуты поперёк площадки и выходили за медь —
  ошибка разводки, а не решение. Исправлено по фото донора: паз вдоль площадки; BAT− — прямоугольная
  площадка, как у донора; BAT+ — овальная (прямоугольная не проходит по зазорам к Q1 и дорожкам).
  Gerber для заказа — `hardware/fab/Gerber_PCB1_v3a_2026-11-26.zip`.
- **Кварц C7420782 оставлен:** на складе JLCPCB 1 419 шт. (26.11.2026), замена не нужна.
- **Настройка по BLE (`add-remote-config`), код без железа:**
  - коды кнопок больше не константы — блок настроек во флеше, **одна копия с CRC** (сначала было сделано две копии
    со счётчиком — владелец отменил: при прерванной записи пульт просто настраивают заново; спецификация
    «Сохранность настроек» поправлена); стирание блоком 4 КБ (для чипа с ID CH592A SDK зависает на меньшем);
    чистый пульт не излучает; для проверок ИК до BLE — сборка `TEST_CODES=1`;
  - BLE — библиотека WCH из SDK, собирается xPack GCC (`-DINT_SOFT`), стек запускается только в режиме настройки;
  - обе кнопки сразу обрывают ИК; 4 с — режим настройки; 60 с без команд — выключение;
  - страница — `web/index.html` + `web/protocol.js` (логика вынесена ради тестов, сборки нет); код ошибки пульта
    Chrome странице, вероятно, не отдаёт (гипотеза) — страница проверяет значения сама.
  Протокол — `docs/ble_protocol.md`.
