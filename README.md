# UlpanIR

ИК-пульт на две кнопки в корпусе селфи-брелока (донор — AB Shutter3). Первая цель — включать и
выключать проектор Optoma X341. Питание — CR2032. Коды и настройки задаются с компьютера: веб-страница
в Chrome или Edge подключается к пульту по Bluetooth (Web Bluetooth).

## Как работает

- **Кнопка A или B** отправляет свой NEC-код на несущей 38 кГц. Пока кнопка удерживается, кадр
  повторяется 3 раза в секунду. Индикатор вспыхивает на каждый кадр.
- **Кнопка без кода** ничего не излучает, индикатор медленно мигает 3 раза.
- **Обе кнопки ≥ 4 с** включают режим настройки: индикатор мигает, пульт виден по BLE как
  `IR-Remote-XXXX`. Без команд 60 с пульт выключается. Страница шлёт пинг раз в 30 с, а через 9 мин
  спрашивает, продолжать ли сессию.
- **Между нажатиями** пульт полностью обесточен мягкой защёлкой питания.
- **На севшей батарейке** (< 2,4 В) пульт всё равно отправляет код, а потом предупреждает плавным
  импульсом индикатора 2 с.

## Решения

| Что | Решение |
|---|---|
| МК | WCH CH592F (BLE 5.4, RISC-V, QFN-28 4×4), JLCPCB C39831287 — вместо nRF52810: в 4–8 раз дешевле, есть на складе |
| Питание | CR2032; мягкая защёлка P-MOSFET IRLML6401 + N-MOSFET IRLML6344, кнопки через диоды, 100 нФ от дребезга |
| ИК | 2 × VSMY14940 (940 нм, боковые), второй через перемычку JP1; замена — Amicc A-SP158IR1C-A02-2D на том же посадочном месте |
| Индикатор | один красный светодиод на ШИМ, ≤ 2 мА, светится от 2,2 В |
| Прошивка | SDK WCH `openwch/ch592`, RISC-V GCC; заливка встроенным загрузчиком по USB/UART |
| Плата | EasyEDA Pro, сборка JLCPCB (Economic PCBA) |

Полные требования, решения и задачи — в `openspec/changes/`:

1. `add-ir-nec-transmit` — NEC на отладочной плате CH592F.
2. `add-remote-config` — настройки, BLE, веб-страница.
3. `add-power-latch` — макет защёлки и замеры.
4. `add-board-hardware` — плата, заказ, проверка на проекторе.
