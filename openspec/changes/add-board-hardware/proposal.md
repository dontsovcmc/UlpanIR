# Proposal

## Why

После проверки ИК, настройки и питания на макете нужна своя плата в корпусе брелока. Четвёртая, последняя задача пульта: плата, заказ на JLCPCB, прошивка через WCH-LinkE и проверка готового пульта на проекторе.

## What Changes

- Замеры корпуса-донора (брелок типа AB Shutter3).
- Проект EasyEDA Pro: МК WCH CH592F по эталонной схеме WCH, защёлка с номиналами из `add-power-latch`, ИК-каскад на двух VSMY14940 с JP1, гребёнка прошивки и тестового стенда J1 1×9 2,54 мм.
- Gerber, BOM с кодами LCSC, CPL; заказ платы и сборки на JLCPCB.
- Первая прошивка WCH-LinkE по 2-проводной отладке через J1; проверки готового пульта: питание, BLE в корпусе, дальность до Optoma X341.

## Capabilities

### New Capabilities
- `board-hardware`: плата и корпус — эталонная схема WCH, радио в корпусе, ИК-светодиоды и JP1, гребёнка прошивки, габариты, изготовление на JLCPCB, дальность.

## Impact

- Новый каталог `hardware/` (проект EasyEDA `easyeda/`, схема `schematic/`, производство `fab/`, версии разводки `pcb_versions/`, `enclosure.md`), дополнение `docs/measurements.md`.

- Внешнее: EasyEDA Pro, JLCPCB, WCH-LinkE, проектор Optoma X341 для проверки.
