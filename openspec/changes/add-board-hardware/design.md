# Design

## Context

Ссылки на референс Nordic, готовые проекты и детали JLCPCB — README, раздел 3. BOM МК — `BOM_MCU_nRF52810_QCAA.csv` (коды LCSC есть только у МК и кварца). Номиналы питания — из `add-power-latch`. Требования — `specs/board-hardware/spec.md`.

## Goals / Non-Goals

**Goals:**
- Одна рабочая ревизия платы, собранная JLCPCB.

**Non-Goals:**
- Свой корпус, серийная партия, сертификация.

## Decisions

### Схема МК строго по референсу Nordic
Антенна и кварц — самое рискованное место; любые отклонения записываются. Альтернатива — импорт готового проекта (positron96, tscircuit) — допустима как источник разводки, если совпадает с референсом.

### EasyEDA Pro → JLCPCB
Библиотеки LCSC под рукой, заказ из редактора. Две стороны меди, сплошная земля, via у каждого VSS, чистая зона под антенной. Детали на одной стороне, чтобы хватило Economic PCBA.

### Светодиоды у торца
Боковые VSMY14940 у переднего торца, второй — через JP1 (по умолчанию разомкнута, ток из CR2032 меньше).

### Первая прошивка — ESP32_nRF52_SWD
Без покупного программатора; OpenOCD через ST-Link — запасной путь.

## Risks / Trade-offs

- [Антенна расстроена в корпусе] → строгий референс, проверка BLE на 3 м в корпусе.
- [ESP32_nRF52_SWD не поддерживает 52810 явно] → OpenOCD.
- [Габариты модели оценочные] → замер корпуса до разводки контура.
- [Коды Optoma X341 не подтверждены] → взять из PDF руководства или снять приёмником до проверки дальности.
