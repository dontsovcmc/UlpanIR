# Design

## Context

МК — WCH CH592F (JLCPCB C39831287), решение владельца 25.11.2026 вместо nRF52810. Обвязка — по эталонной схеме WCH (мышь CH592F-3MODE-MS в `openwch/ch592`, `Application/8K_PollingRateWirelessMouse/hardware/`) и даташиту CH592 V1.7. `docs/source_package_v5_nrf/BOM_MCU_nRF52810_QCAA.csv` — исторический. Номиналы питания — из `add-power-latch`. Требования — `specs/board-hardware/spec.md`.

## Goals / Non-Goals

**Goals:**
- Одна рабочая ревизия платы, собранная JLCPCB.

**Non-Goals:**
- Свой корпус, серийная партия, сертификация.

## Decisions

### Схема МК по эталонной схеме WCH
Согласование антенны встроено в CH592: вывод ANT идёт на антенну напрямую (даташит: «recommended to connect the antenna directly»). Внешние: кварц 32 МГц, развязка VDD33/VIO33, VDCIA, VINTA, при включении DC-DC — дроссель 10 мкГн и конденсаторы по эталонной схеме. Антенна — печатная, по образцу эталонной платы WCH; отклонения записываются.

### EasyEDA Pro → JLCPCB
Библиотеки LCSC под рукой, заказ из редактора. Две стороны меди, сплошная земля, чистая зона под антенной, развязка у выводов питания. Детали на одной стороне, чтобы хватило Economic PCBA.

### Светодиоды у торца
Боковые VSMY14940 у переднего торца, второй — через JP1 (по умолчанию разомкнута, ток из CR2032 меньше).

### Первая прошивка — встроенный загрузчик CH592
Загрузчик в ПЗУ чипа (24 КБ BootLoader) принимает прошивку по USB или UART; вход — вывод BOOT при включении (по эталонной схеме: площадки TX, BOOT, 3V3, GND). На плате — площадки UART/USB, BOOT, VBAT, GND и 2-проводной отладки (PB14/PB15) для WCH-LinkE.

## Risks / Trade-offs

- [Антенна расстроена в корпусе] → строгий референс, проверка BLE на 3 м в корпусе.
- [Порог VIH 2,0 В у CH592 (при 3,3 В) — на батарейке ниже ~2 В кнопки могут читаться ненадёжно] → проверка на макете.
- [Габариты модели оценочные] → замер корпуса до разводки контура.
- [Коды Optoma X341 не подтверждены] → взять из PDF руководства или снять приёмником до проверки дальности.

## Защёлка питания: утверждённая схема (25.11.2026)

Типовая схема «Soft power button with sense output» (hackaday.io/project/27886), адаптированная под CR2032 и две кнопки. Утверждена владельцем.

| Элемент | Назначение | Номинал / деталь |
|---|---|---|
| Q1 | P-MOSFET в плюсе батареи | IRLML6401 (VGS(th) −0,40…−0,95 В; RDS(on) ≤ 0,125 Ом при −1,8 В — даташит Infineon) |
| R1 | затвор Q1 → VBAT | 100 кОм (не 1 МОм: утечка D3/D4 1 мкА × 1 МОм приоткрыла бы Q1) |
| Q2 | N-MOSFET удержания, сток → затвор Q1 | IRLML6344 (VGS(th) 0,5…1,1 В) |
| R2 | затвор Q2 → GND | 1 МОм |
| D1, D2 | кнопка A/B → затвор Q1 | 1N4148WS, SOD-323 |
| D3, D4 | кнопка A/B → GPIO МК (внутренняя подтяжка CH592: 25–90 мкА) | Шоттки с малой утечкой; VF ≈ 0,3 В при VIL CH592 = 0,9 В |
| Cb1, Cb2 | узел кнопки A/B → GND, против дребезга | 100 нФ (решение владельца) |
| Rg + Cm | плавный старт Q1 | 100 кОм + 33 нФ |
| C | затвор Q1 – VBAT, против дребезга | 100 нФ (оценка, проверить на макете) |

Не проверено: IDSS IRLML6401, утечка Шоттки при 3 В, выбор оригинала Infineon (LCSC C3034) против вторых источников, совместная работа Cm и C — проверка в `add-power-latch`.
