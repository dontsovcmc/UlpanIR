# Proposal

## Why

Нужен свой маленький ИК-пульт на две кнопки (первая цель — включение и выключение проектора Optoma X341), который работает от CR2032 годами и перенастраивается без перепрошивки. Готовые брелоки-пульты либо обучаемые и громоздкие, либо зашиты на один код. Пакет исходных материалов (схема v5, модель брелока, BOM МК, расчёт ИК-каскада) уже собран в этом репозитории — пора превратить его в устройство.

## What Changes

- Новая плата на nRF52810-QCAA в корпусе двухкнопочного брелока (донор AB Shutter3): МК по референсу Nordic, мягкая защёлка питания, ИК-каскад на двух VSMY14940 с перемычкой JP1, площадки SWD.
- Прошивка: каждая кнопка отправляет свой NEC-код на 38 кГц; при удержании — повторы; после отпускания пульт полностью обесточивается.
- Режим настройки: зажать обе кнопки 2–3 с → пульт около минуты виден по BLE, затем выключается сам.
- Веб-страница настройки (Chrome/Edge, Web Bluetooth): ввод NEC-адреса и команды для каждой кнопки, частоты повторов, чтение текущих настроек, запись в пульт, проверка «отправить код сейчас».
- Настройки хранятся во флеше МК и переживают замену батарейки.
- Первая версия — только протокол NEC; обучения от родного пульта нет (ИК-приёмника на плате нет).

## Capabilities

### New Capabilities
- `ir-transmit`: отправка ИК-кода по нажатию кнопки — протокол NEC, несущая, повторы при удержании, дальность.
- `remote-config`: режим настройки по BLE и веб-страница — вход в режим, GATT-сервис, формат настроек, хранение во флеше, тайм-аут.
- `power-management`: питание от CR2032 — мягкая защёлка, ток покоя, ограничение пиков и броска, поведение на севшей батарейке.
- `board-hardware`: плата и корпус — МК по референсу Nordic, ИК-светодиоды, SWD, требования к изготовлению на JLCPCB.

## Impact

- Новые каталоги в репозитории: `hardware/` (проект EasyEDA Pro, Gerber, BOM, CPL), `firmware/` (nRF Connect SDK / Zephyr, цель `nrf52dk/nrf52810`), `web/` (статическая страница настройки).
- Внешние зависимости: nRF Connect SDK, EasyEDA Pro, JLCPCB (плата и сборка), ESP32 с прошивкой ESP32_nRF52_SWD для первой прошивки чистого чипа.
- Страница настройки требует HTTPS и браузер с Web Bluetooth (Chrome/Edge; Firefox и Safari не поддерживаются).
- Открытые данные из README (коды Optoma X341, габариты корпуса, параметры FET и светодиодов) нужно получить до заказа плат.
