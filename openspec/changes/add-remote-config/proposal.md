# Proposal

## Why

Коды кнопок должны меняться без перепрошивки — с компьютера через браузер. Вторая задача пульта: опирается на ИК-модуль из `add-ir-nec-transmit`, делается целиком на отладочной плате CH592F.

## What Changes

- Блок настроек во флеше (коды A и B, частота и вид повтора), переживающий отключение питания; прерванная запись даёт ненастроенный пульт, а не испорченные коды.
- Режим настройки: обе кнопки ≥ 4 с → BLE-реклама, выключение через 60 с без команд.
- Свой BLE-сервис: чтение и запись настроек, статус (версия, напряжение батарейки), команда «отправить код A/B».
- Веб-страница `web/index.html` на Web Bluetooth (Chrome/Edge), публикация на GitHub Pages.
- Константы кодов из первой задачи заменяются чтением настроек; ненастроенная кнопка ничего не излучает.

## Capabilities

### New Capabilities
- `remote-config`: режим настройки по BLE и веб-страница — вход, тайм-аут, состав и запись настроек, хранение, проверка кода, совместимость браузеров.

## Impact

- `firmware/` (DataFlash, BLE), новый `web/`, `docs/ble_protocol.md`.
- Страница требует HTTPS и Chrome/Edge; Firefox и Safari не поддерживаются.
- Выключение по тайм-ауту на отладочной плате — это остановка рекламы; полное обесточивание появится в `add-power-latch`.
