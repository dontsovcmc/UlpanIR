# Design

## Context

ИК-модуль готов в `add-ir-nec-transmit` (коды — константы). Требования — `specs/remote-config/spec.md`.

## Goals / Non-Goals

**Goals:**
- Настройка с ноутбука и Android-телефона в Chrome, отлаженная на отладочной плате CH592F.

**Non-Goals:**
- Сопряжение BLE и пароль: окно открывается только физическим удержанием двух кнопок.
- OTA-обновление прошивки.

## Decisions

### Настройки: один блок в DataFlash, одна копия с CRC
Одна запись фиксированного формата с версией и CRC в начале DataFlash CH592 (32 КБ, стирание сектора 6–30 мс). При старте запись с верной CRC берётся, иначе пульт ненастроен. Прерванная запись (вынули батарейку) даёт неверную CRC — пульт стартует чистым и его настраивают заново; мусорные или смешанные коды не излучаются. Решение владельца 26.11.2026: две копии со счётчиком отклонены как лишняя сложность — настройка редкая, повторить её просто.

Формат блока v1 (little-endian): `version u8`; для A и B: `flags u8` (бит 0 — назначено, бит 1 — 16-битный адрес), `address u16`, `command u8`; затем `repeat_hz u8` (1–10), `repeat_mode u8` (0 — полный кадр, 1 — NEC-повтор).

### BLE: свой GATT-сервис
128-битный сервис: `config` (чтение/запись блока целиком; ошибка валидации — ATT-код приложения), `status` (чтение: версия прошивки, мВ батарейки), `ping` (запись без данных: продлевает режим на 60 с), `test` (запись: 0 — A, 1 — B, текущим кодом из последнего записанного или переданного блока). UUID генерируются один раз и фиксируются в `docs/ble_protocol.md`. Альтернатива — сервис-«UART» с текстовыми командами: нужен парсер и свой протокол.

Имя в рекламе — «IR-Remote-XXXX», XXXX — последние 4 hex-цифры адреса.

### Тайм-аут: сторож на стороне пульта, вежливость на стороне страницы
Пульт выключается через 60 с без любой команды — это единственная защита от забытого включённого пульта, она не зависит от страницы. Страница держит сессию пингом раз в 30 с (запас ×2) и через 9 мин спрашивает, нужна ли сессия ещё: так забытая вкладка не держит пульт включённым часами. Отсчёт 9 мин идёт от подключения или от последнего «Продолжить».

### Страница: один статический HTML без сборки
Встроенный JS, публикация на GitHub Pages. Поля: hex-адрес, галка 16 бит, hex-команда, частота, вид повтора; предпросмотр байтов кадра; кнопки «Подключить», «Прочитать», «Записать», «Отправить A/B». Альтернатива — фреймворк со сборкой: лишний для одной формы.

## Risks / Trade-offs

- [Web Bluetooth на macOS/Android ведёт себя по-разному при переподключении] → проверка на обеих платформах в задачах.
- [Кто-то рядом перепишет коды за 60 с окна] → принято: нужен физический доступ к пульту.
