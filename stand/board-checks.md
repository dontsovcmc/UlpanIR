# Проверки стенда на плате

Протокол проверок раздела 8 `openspec/changes/add-test-stand/tasks.md`: что сделать руками, когда придут ESP32-C6
Super Mini и платы пульта. Каждый сценарий «на плате» из спек `stand-port`, `stand-flash`, `stand-test` — здесь.

Все проверки ниже **не выполнены**: железа нет. После проверки — дата, результат и числа в колонку «Итог», расхождения
с гипотезами — в `design.md` (§5, §6, Risks).

Команды в порт стенда — через `uv run stand/host/stand.py monitor '#команда' …` или любой терминал (RTS=0, DTR=0).

## 8.1 Стенд сам по себе

| Что | Как | Ожидаем | Итог |
|---|---|---|---|
| Прошивка стенда | `cd stand && pio run -e esp32c6 -t upload` | порт `/dev/cu.usbmodem*` с VID 0x303A | |
| «Открытие порта» (stand-port) | стенд работает > 10 с; трижды `monitor '#info'` с выходом по Ctrl-C | `uptime` растёт от раза к разу | |
| Куча (design §5) | `#heap` | `max` больше 300 КБ (образ 256 КБ одним куском) | |

## 8.2 Проводка и питание

Проводка — таблица в `README.md`, батарейка вынута.

| Что | Как | Ожидаем | Итог |
|---|---|---|---|
| Нажатие включает пульт | `#press a 100`, сразу `#power` | `# press: a 100`, `# power: вкл …`; лог пульта идёт в порт | |

## 8.3 Подпитка и порог «выкл»

| Что | Как | Ожидаем | Итог |
|---|---|---|---|
| «Выключенный пульт не подпитывается» (stand-port) | пульт выключился сам, стенд простоял 10 с, `#power` | не больше 0,3 В | |
| «Пульт выключился сам» (stand-test) | `#press a 100`, через 2 с `#power` | `# power: выкл …` | |
| Спад VBAT_SW | `#press a 100`, затем `#power` каждые 100 мс 3 с | время до 1,5 В и до 0,3 В; запас «выкл не позже 2 с» достаточен | |
| Порог | по спаду: при каком напряжении пропадает лог пульта | порог `POWER_ON_MV` (`src/core/adc.h`) поправить, если нужно; записать в design §6 | |

Если подпитка больше 0,3 В — по очереди отключить J1.8, J1.6/J1.7, найти линию. Для J1.8 проверить, что подтяжка RX
UART снята (design §7, гипотеза).

## 8.4 Прошивка CH592

| Что | Как | Ожидаем | Итог |
|---|---|---|---|
| «Платы нет» (stand-flash) | J1 не подключена, `#chip` | `# chip: нет ответа` не позже 2 с | |
| «Плата на месте» (stand-flash) | `#chip` | `# chip: CH59x uid=…` | |
| «Пустой чип прошивается» (stand-flash) | чистый CH592F, `make stand-flash` | `# flash: записано …`; после ответа пульт работает | |
| «Прошивка пульта» (stand-flash) | `make stand-flash` с `remote.bin` (около 155 КБ) | ответ не позже 60 с; затем `#press a 100` даёт `boot: UlpanIR fw …` в логе | |
| «Пульт снова чистый» (stand-flash) | записать коды, `#erase data`, `#press a 100` с `#ir on` | `# erase: настройки стёрты`, ИК-кадров нет, `A has no code` | |

При отказе `#chip`:
1. `wlink status` с WCH-LinkE на той же плате. Если LinkE тоже не видит — 2-проводная отладка на чипе выключена
   (риск `add-board-hardware` 4.1).
2. Если LinkE видит — увеличить полупериоды в `SetProtocolSpeed` (`src/port/bitbang_rvswd_c6.h`) в 4 раза и
   повторить.
3. Результат — в design Risks.

## 8.5 ИК

| Что | Как | Ожидаем | Итог |
|---|---|---|---|
| Приём в 10–30 см | коды записаны, `#ir on`, 10 раз `#press a 100` | 10 строк `# ir: nec 0x32 0x02 …` из 10 | |
| Повтор | `#press a 2000` | 6–7 кадров, промежуток 333 мс ±10 % | |

Если кадры приходят как `неразобрано` — посмотреть число меток. Если RMT режет кадр на части (гипотеза design §8) —
перейти на драйвер RMT ESP-IDF.
